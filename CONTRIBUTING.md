# Contributing

Thanks for helping improve `dsh-docling`.

## Development loop

Use Node `^22.19.0 || >=24` and pnpm 10 or later.

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Keep changes focused. New input paths or network behavior require security
tests; changes to Docling's wire format require fixture-backed normalization
tests; changes to tool behavior require the real DSH ToolRuntime lifecycle test
to keep passing.

## Docling integration testing

The standard suite uses a local HTTP server and never downloads Docling models.
To test a running Docling Serve instance, set `DOCLING_BASE_URL` (and optionally
`DOCLING_API_KEY`) before running `pnpm test:integration`.

Do not commit API keys, document contents, coverage folders, packed tarballs,
or generated `lib/` files. Release artifacts are generated by `pnpm build`.
