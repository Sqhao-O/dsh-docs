# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.
Treat contributors and users with empathy; discuss ideas in good faith; and
avoid personal attacks, discriminatory language, or intimidation.

Project maintainers may remove, edit, or reject contributions and comments
that violate these expectations. Report concerns privately through a GitHub
security advisory or by contacting a maintainer through GitHub.

By participating in this project, you agree to follow these standards.
